# Hand-edited agents

Everything in `agents/` and `agents_lg/` is generated by
`agent_ontology/instantiate.py` from `agent_ontology/specs/`, **except** the
files listed here. Those were edited by hand after generation, and regenerating
them silently deletes working behaviour.

| File | What is hand-written | Covered by |
|---|---|---|
| `agents/babyagi_agent.py` | Tool-call execution (`_execute_tool_calls`, `_dispatch_runtime_tool`, `_normalize_tool_call_list`, `_tool_call_to_runtime_payload`) and the build-intent scaffold fallback (`_build_default_todo_api_scaffold`, `_looks_like_todo_api_request`, `_detect_no_questions_mode`, `_looks_like_questioning_result`, `_constraints_text`) | `tests/test_babyagi_runtime.py` |
| `agents/autogpt_agent.py` | Critique retry-loop progress forcing and scaffold fallback, edited inside generated functions | `tests/test_autogpt_runtime.py` |

## How this was found

A regeneration on 2026-08-25 dropped nine functions from `babyagi_agent.py` and
broke three runtime tests. The behaviour had never been moved back into the
generator, and nothing recorded that these two files were not purely generated.

`tests/test_generated_agents_are_current.py` now fails if any *other* agent
drifts from what the generator produces, so the exception stays a short list
rather than an unknown one.

## Generator changes still apply to them

The drift test exempts these two files, so a fix in `instantiate.py` does not
reach them on regeneration. Apply the same delta by hand: generate the file
with the old and the new generator, `diff -u` the two outputs, and `patch` the
hand-edited file with that diff. On 2026-09-29 both files still carried the
round-1 `call_embedding` bug that every other agent had been fixed for.
`tests/test_generated_runtime_contract.py` runs both through the runtime
contract, so a missed delta that matters there fails a test.

## The real fix

Move the tool-call execution and scaffold-fallback logic into
`instantiate.py` so every generated agent gets it, then delete this file and
regenerate. Until then, do not run `ao-instantiate --all` over `agents/`
without restoring these two files afterwards.
